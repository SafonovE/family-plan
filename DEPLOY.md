# Размещение

Требования: PHP 8.2+, PDO SQLite или PDO MySQL и действующий HTTPS. Для MySQL нужны InnoDB, utf8mb4 и MySQL 5.7+ либо совместимая MariaDB.

## Структура

```
family/
  public/   # единственный DocumentRoot сайта
  src/
  private/  # конфигурация, SQLite, сессии и копии
  bin/
```

Не загружайте закрытую папку внутрь публичного корня. PHP должен иметь права записи в `private`; не выдавайте 777. Пример конфигурации — `private/config.example.php`. Используйте новый случайный `installKey` длиной 64 hex-символа; примерный ключ заблокирован приложением.

## SQLite

Создайте закрытый `private/config.php` с полями:

```php
<?php
return [
  'dsn' => 'sqlite:'.__DIR__.'/family.sqlite',
  'installKey' => 'REPLACE_WITH_64_RANDOM_HEX_CHARACTERS',
  'secure' => true,
  'privateDir' => __DIR__,
  'tablePrefix' => 'family_',
];
```

Сгенерируйте ключ на своём сервере: `php -r "echo bin2hex(random_bytes(32));"`. Не используйте один ключ для разных установок. Существующую конфигурацию и базу сохраняйте при обновлениях.

## MySQL

Создайте выделенную БД и пользователя. Заполните закрытый конфиг по примеру либо задайте в своей серверной сессии `FAMILY_DB_HOST`, `FAMILY_DB_NAME`, `FAMILY_DB_USER`, `FAMILY_DB_PASSWORD` и выполните `php bin/configure.php --mysql`. Секреты не передавайте аргументами командной строки или через Git. Проверка соединения: `php bin/configure.php --check`.

Для обеих конфигураций `secure` на хостинге должен быть `true`. Принудительно перенаправляйте HTTP на HTTPS. Рекомендуется `post_max_size` не меньше 8 МБ, для MySQL `max_allowed_packet` не меньше 16 МБ.

## Приёмка

1. Создайте два входа и сохраните коды восстановления отдельно.
2. Создайте категорию, план и пробную операцию. Перезагрузите страницу, измените операцию, удалите её и проверьте историю.
3. Скачайте JSON и проверьте восстановление сначала на отдельной тестовой установке.
4. Проверьте, что без входа API бюджета отвечает 401, а пути `private/config.php`, `private/source.json` и `src/App.php` недоступны через сайт.
5. Проверьте фактический телефон, офлайн-просмотр и черновик. Эмуляция размеров не заменяет настоящий Safari.

## Обновление

Сначала сохраните JSON вне хостинга и прежние файлы. Не перезаписывайте конфигурацию, базу или сессии. Для новой версии меняйте идентификатор статического кэша в `public/sw.js`. После обновления закройте все вкладки приложения и PWA, затем откройте снова. Откат кода не восстанавливает данные автоматически.
