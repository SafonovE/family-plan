# Проверка публичной версии

31 октября 2026. Проверена отдельная копия с пустым бюджетом; персональный снимок и рабочая база не используются.

## Выполнено

- PHP 8.4.27: синтаксис всех 6 PHP-файлов без ошибок; синтаксис клиентского JavaScript и service worker без ошибок.
- `node tests/smoke.mjs`: 6 групп проверок. Закрытость без входа, два равноправных участника, отсутствие обязательного личного снимка, ручной ввод, точные копейки, безопасный повтор запроса, устаревшая запись, JSON-предпросмотр и восстановление со страховочной копией.
- Браузер Chromium: первоначальная настройка, ручное создание категории, расход, сохранение после перезагрузки, отсутствие персонального мастера переноса. Ширины 1440 и 390 px без горизонтального переполнения; ошибок JavaScript нет.
- Отсутствие снимка таблицы проверено регрессией: сначала API возвращал предупреждение PHP вместо JSON, после исправления отвечает понятным 404. Первоначальный интерфейс публичной копии больше не зависит от этого снимка.
- Публикуемые файлы проверены на известные персональные идентификаторы, адрес рабочего сайта, ключ настройки и локальные конфигурации. Исходная рабочая папка сохранена без изменений.

## Ограничения

Этот прогон относится к чистой публичной копии с вымышленными данными. Реальный iPhone, VoiceOver, длительное офлайн-хранение, конкретный сервер MySQL и предельная нагрузка этим прогоном не проверялись. После собственного размещения нужна приёмка из DEPLOY.md. Переносной PHP и браузерные инструменты не включены в Git.
