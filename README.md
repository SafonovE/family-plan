# Семейный план

Веб-приложение для общего месячного бюджета двух участников. Русский интерфейс, рубли, адаптация для телефона и ПК, установка на домашний экран iPhone через Safari.

## Возможности

- Два личных входа с равными правами.
- Доходы, расходы, категории, месячные планы и обычные суммы для будущих месяцев.
- Точные расчёты в целых копейках. Начальный остаток и отметка о полноте доходов.
- Защита от одновременной перезаписи и дубликатов при повторной отправке.
- История изменений с отменой, полная JSON-копия, предварительный просмотр восстановления, CSV операций.
- Сохранённый бюджет и один локальный черновик расхода без сети. Отправка черновика вручную.

Публичная версия запускается с пустым бюджетом. Личные данные, снимки Google-таблиц, реальные учётные записи, адрес рабочего сайта и резервные копии не входят в репозиторий. Первоначальный экран предназначен для ручного создания категорий или восстановления собственной JSON-копии. Персональный перенос из исходной таблицы скрыт в публичном интерфейсе.

## Быстрый локальный запуск

Нужны PHP 8.2+ с PDO SQLite. Node нужен только для разработческих проверок.

```sh
php bin/configure.php --local
php -S 127.0.0.1:18426 -t public
```

Откройте `http://127.0.0.1:18426/`. В первом окне введите ключ `installKey` из закрытого `private/config.php`, создайте два входа и сохраните коды восстановления отдельно. Ключ также можно получить фрагментом адреса командой `php bin/configure.php --setup-fragment`. Не публикуйте этот ключ.

В Windows можно использовать VBS-запускатели, если переносной PHP распакован в `.runtime/php/` и содержит `ext/pdo_sqlite` и `ext/pdo_mysql`. Сам PHP в Git не включён. Для обычного установленного PHP используйте команды выше и включите PDO SQLite в его `php.ini`.

## Размещение

См. [DEPLOY.md](DEPLOY.md). Используйте HTTPS и укажите корнем сайта только `public`. Данные, конфигурация, сессии и копии должны находиться снаружи публичной папки. Поддерживаются SQLite и MySQL/MariaDB через PDO. Node-сервер, внешние CDN и банковские интеграции приложению не нужны.

## Проверки

```sh
node --check public/app.js
node tests/smoke.mjs
```

Для проверки API нужны Node 22+ и PHP с PDO SQLite в PATH. Можно задать `PHP_BIN`; для переносного Windows PHP дополнительно задайте `PHP_EXT_DIR`. Тест создаёт временную базу с вымышленными данными и не обращается к рабочему бюджету. Результаты подготовки публичной версии: [VERIFICATION.md](VERIFICATION.md).

## Сохранность и ограничения

Скачивайте JSON после важных изменений. CSV не заменяет полную копию. Страховочная копия перед восстановлением остаётся на том же сервере; независимые регулярные копии нужно настроить отдельно.

Первая версия рассчитана на двух участников, 500 категорий, 20 000 операций и 4,5 МБ бюджета вместе с историей. Копия и черновик в браузере могут исчезнуть при очистке данных сайта. Выход очищает их. Полной офлайн-синхронизации нет.

Шрифт Manrope включён с лицензией OFL в `public/assets/OFL-Manrope.txt`.
